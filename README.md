# MD Reader

一个**零依赖、单文件、离线可用**的文档阅读与编辑工具。双击 `index.html` 就能用，不需要安装任何东西，也不需要联网。

## 为什么写它

每次要看 `.md` 都要找编辑器、开 IDE、或者忍受 GitHub 的原始视图；想转成 Word 发给别人更是麻烦。这个东西的目标只有两个：**能顺手地读，能顺手地转。**

## 怎么用

1. 双击 `index.html`（建议存成浏览器书签，或固定到任务栏）。
2. 把文件拖进窗口；**更推荐直接拖整个文件夹**——里面所有文档会列在左侧，点一下就切换，文档里引用的本地图片也会一起显示。
3. 想更省事：用 `open-md.bat` 把 `.md` 的默认打开方式设成它，以后双击 md 直接看（见下文）。

## 支持的格式

| 类型 | 扩展名 | 处理方式 |
| --- | --- | --- |
| Markdown | `.md` `.markdown` `.mdown` `.mkd` `.mdx` | 完整渲染，支持目录、锚点、内链跳转 |
| HTML | `.html` `.htm` | 消毒后直接渲染，自动解析相对路径图片 |
| 表格 | `.csv` `.tsv` | 渲染成表格（正确处理引号与转义） |
| JSON | `.json` `.jsonc` `.json5` | 自动格式化 + 高亮，解析失败则按原文显示 |
| 代码 | `.py` `.js` `.ts` `.java` `.c` `.cpp` `.go` `.rs` `.sql` `.sh` 等 60+ 种 | 语法高亮展示 |
| 纯文本 | `.txt` `.log` `.ini` `.toml` `.yml` 等 | 原样保留排版 |

图片（png/jpg/svg/gif/webp 等）会被自动收录为文档资源；压缩包、Office 二进制、音视频等会跳过并提示。

## 编辑

按 `Ctrl`+`E` 或点顶栏「编辑」进入编辑模式：左侧是 Markdown 源码，右侧是实时预览（输入停顿 0.26 秒后刷新）。

- 工具栏支持：加粗、斜体、删除线、行内代码、H1–H3、无序/有序/任务列表、引用、链接、图片、表格、代码块、分割线
- 列表里回车自动续行、空列表项回车退出列表；`Tab` 插入两个空格
- 保存（`Ctrl`+`S`）：
  - 如果文件是通过「打开」按钮（File System Access API）载入的，**直接写回原文件**
  - 否则另存为下载（浏览器安全沙箱不允许网页静默改写磁盘文件）

## 导出 / 转换

点顶栏的下载图标，或按 `Ctrl`+`K` 输入 `word` / `txt` / `html`：

| 格式 | 说明 |
| --- | --- |
| **HTML** | 单文件网页，图片内联为 data URL，可直接分享 |
| **Word (.docx)** | 真正的 OOXML 文档，标题层级/列表/表格/代码块/引用/图片都在，图片会自动从 SVG 光栅化成 PNG 内嵌；代码保留语法着色。生成器是自己写的（zip + OOXML），**不依赖任何第三方库** |
| **纯文本 (.txt)** | 去掉所有标记，保留标题分行、列表符号、表格制表符对齐 |
| **打印 / PDF** | 已做打印排版优化（隐藏界面、避免代码块跨页断裂） |

## 让双击 .md 直接打开（可选）

仓库里附带了 `open-md.bat`：把它设为 `.md` 的默认打开方式，以后双击任何 md 都会直接用 MD Reader 打开。

原理：`file://` 页面默认不能读取本地文件，脚本会

1. 把目标文件的绝对路径写进同目录的 `_last_open.txt`；
2. 用一个**独立 profile** 启动本机 Chrome / Edge（自动探测），带上 `--allow-file-access-from-files`，打开 `index.html?autofile=1`。

独立 profile 是必要的——如果复用已运行的浏览器进程，启动参数会被忽略，功能就失效了。

设置默认打开方式：右键任意 `.md` → 打开方式 → 选择其它应用 → 勾选「始终使用此应用」→ 浏览到 `open-md.bat`。

> 不使用这个脚本也完全不影响正常使用，只是每次需要手动拖入文件。

## 开发

仓库里的 `index.html` 是**构建产物**，源码在 `src/`：

```
src/
  app.js           应用逻辑（渲染分派、文件树、搜索、编辑、导出调度）
  export-docx.js   Word 导出（zip + OOXML 生成器）
  style.css        样式（主题变量 + 代码高亮配色）
  template.html    页面骨架
  vendor/          marked / DOMPurify / highlight.js（构建时内联，离线可用）
scripts/
  build.js         把 src/ 内联打包成单个 index.html
  build-hljs.js    用 esbuild 打包 highlight.js，产出 src/vendor/hljs.bundle.js
test/
  smoke.js         真实 Chrome 跑的冒烟测试（78 项）
  check-docx.py    用 Python 校验导出的 .docx 结构是否合法
```

```bash
npm i marked@12.0.2 dompurify@3.1.6 highlight.js@11.9.0 esbuild@0.21.5
node scripts/build-hljs.js    # 只需跑一次
node scripts/build.js          # 产出 index.html
node scripts/build.js --watch  # 改 src/ 自动重建
node test/smoke.js             # 冒烟测试
```

测试覆盖：渲染 / 代码高亮 / 图片解析 / 内链跳转 / 搜索 / 主题 / 命令面板 / 拖拽（含文件夹递归、
`items` 混入字符串条目、二进制跳过）/ 编辑模式 / 三种导出格式 / 多格式查看 / 中文空格路径自动打开。
